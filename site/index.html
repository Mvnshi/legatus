Keep your coding agents working when a login runs out.

Legatus runs Codex and Claude Code in parallel on your own machine, spread across your own subscriptions. Every task gets its own branch, your checks, an independent review, and a report you read before you merge.

What happens at a usage limit

  1. 1

    The login runs out

    An agent stops with a usage-limit error. Legatus recognises it and reads when the login resets.

  2. 2

    The work is saved

    Whatever was written is committed on the run's branch, and the next attempt is told exactly where things stand.

  3. 3

    Another login continues

    The pool hands the task to a login that still has usage. The checks and the review still run afterwards.

  4. 4

    Or it waits, and carries on

    If every login is out, the run waits for the first reset. It survives a restart, and picks up where it stopped.

What it does

A pool of your own logins

Each login lives in its own folder, signed in with the agent's own login. Legatus never sees a password. Work goes to a login with usage left.

Independent review

A different provider (or at least a different login) reviews read-only. Whatever a reviewer touches is reverted, and no verdict is never an approval.

Safe by default

Secrets are removed before anything is stored. Agents get a scrubbed environment. The agent's own sandbox is checked first. Nothing is published unless you ask.

A cockpit that stays on your machine

Runs, a live journal, reports, diffs, logins and countdowns, and it works on a phone-sized screen. It listens only locally and needs a secret key.

Issues in, pull requests out

Start a task from a GitHub issue (its text is treated as untrusted). A finished run can open a pull request with its report as the description, only when you ask.

Tasks that start themselves

Schedules, and a watcher for labelled issues that only accepts authors you list. Heavy checks run one at a time, so a queue never uses up your memory.

An honest status

Legatus is early. The core is tested on Linux, macOS and Windows with stand-in agents and real git, and it has completed real tasks with the real Codex CLI on Windows. Some things have not been run for real yet: Claude Code, a real usage-limit message, a second real login, a real pull request, and macOS or Linux by hand.

Try it in a minute

You don't need an agent installed to watch a limit being handled.

legatus demo            # a usage limit is hit mid-task and handled
legatus serve --demo    # the same, in the web cockpit

Get a build from Releases (Windows, macOS, Linux), or with Go 1.26+:

go install github.com/Mvnshi/legatus/cmd/legatus@latest

To use it for real you need git and a signed-in Codex CLI or Claude Code:

legatus doctor
legatus accounts add --id main --provider codex --home default
legatus run --repo . --check "npm test" --review "add input validation to the signup form"
